# 课程流程助手 · Course Runner

一个 Chromium MV3 浏览器扩展：自动进入课程章节 → 播放视频 → 完成章节测验 → 进入下一节。
答题用 DeepSeek 接口，取不到答案时可以选择随机补全并导出待复习清单。

> **别卸载重装**：更新时直接把新文件夹拖进 `chrome://extensions` 覆盖即可，卸载会清空 API Key 和全部设置。

- 本项目仅供**个人学习与技术交流**。是否适用于你的课程，请自行判断并遵守所在学校的规定与平台的用户协议。
- 作者不对使用本工具产生的任何后果负责。
- **不要**把你的 API Key、Cookie、课程链接（`courseId` / `clazzid` / `enc`）提交到任何公开仓库或发给任何人。本仓库源码不含任何密钥与账号信息。
- 扩展只在你自己的浏览器里运行，不会把数据上传到除 DeepSeek 接口以外的任何地方。

## 功能

| 能力 | 说明 |
|---|---|
| 自动播视频 | 新版/旧版两种课程目录都支持；播放中的弹题会自动作答并继续 |
| 自动答测验 | 单选、多选、判断、填空；优先读题目图片，读不出来才截图 |
| 三种答题方式 | AI 作答 / 随机作答（零 token）/ 只收集题目 |
| 取不到答案的兜底 | 可勾选"随机选一个"，全部存进待复习清单，事后导出复习 |
| 容错 | 暂态错误退避重试 4 次 → 分批重问 → 必要时自动刷新页面续跑（最多 3 次） |
| 诊断 | 一键导出脱敏日志与页面探针，方便定位问题 |

遇到需要人工处理的场景（验证码、多按钮提交确认、提交状态无法核对）会**停下来并写明原因**，不会瞎点。

## 安装

1. 打开 `chrome://extensions`，右上角打开 **开发者模式**。
2. 把本仓库文件夹（或 Release 里的 zip 解压后的文件夹）**拖进**扩展页面。
3. 打开课程页面，按 **F5** 刷新一次。
4. 点扩展图标 → 齿轮「设置」→ 填入 **DeepSeek API Key**（点「开始」前必须填）。
5. 回到课程目录页，点 **开始**。

> 更新到新版本：不要点「移除」，重复第 2 步覆盖安装，再刷新课程页。

## 配置

| 设置项 | 默认 | 说明 |
|---|---|---|
| API Key | 空 | DeepSeek 密钥，**只存在本地**，不上传 |
| 模型 | `deepseek-chat` | 一般不用改 |
| 答题方式 | AI 作答 | 随机作答完全不调接口；只收集题目则读完暂停 |
| 自动提交章节测验 | 开 | 关掉则填完答案停住，让你检查后手动提交 |
| 取不到答案时随机选一个 | **建议开** | 补全缺失答案并记入待复习 |
| 连续失败自动刷新页面 | 开 | 最多 3 次 |

## 常见问题

**视频不播放 / 卡在 0 秒？**
确认课程标签是当前可见的标签页。Chrome 会节流后台标签的定时器，最小化或切到别的标签会让它变慢。

**接口报错 402？**
余额不足，去 DeepSeek 充值。面板会显示服务商返回的原文。

**接口只为 X/Y 道题给出答案？**
勾选设置里的「取不到答案时随机选一个」，剩下的题会随机补全并存入待复习，不用重跑。

**一直停在同一个地方？**
面板点「复制页面探针」和「导出日志」，把内容贴给 AI 定位。两份输出都已脱敏，不含题目、答案、账号和密钥。

更完整的排查表在 [`docs/完整手册.md`](docs/完整手册.md) 第五章。

## 开发

- 纯原生 JavaScript，无构建步骤、无第三方依赖，`clone` 后即可加载。
- 答案请求已做**分批**（每批 3 题）与**逐题补问**，长卷子不会因为一次请求返空而卡死。
- 契约测试（136 项）用 `vm.createContext` 直接注入源码运行，不依赖浏览器；测试脚本依赖若干历史版本目录，未包含在本仓库内。
