# 课程流程助手 0.1.74 · 完整手册

> 一个「自动刷课」浏览器扩展：自动进章节 → 自动答题 → 自动提交 → 自动播完视频 → 自动进下一节。
> 本手册包含：安装、使用、功能说明、报错处理、出错时给 AI 的提问模板。

---

## 一、这个版本包含什么

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展清单（版本 0.1.74） |
| `content.js` | 页面内主逻辑：识别题目、填写、提交、播放、翻页、容错 |
| `background.js` | 后台：调用 DeepSeek 接口取答案、截图、抓取题目图片 |
| `popup.html` / `popup.js` / `popup.css` | 面板界面：开始/暂停、设置、导出 |
| `安装与使用说明.txt` | 简版说明 + 排障条目 |
| `探针使用说明.txt` / `日志使用说明.txt` | 导出文件里每个字段是什么意思 |
| `AI适配提示词.txt` | 别的 AI 或别的课程页需要适配时的提示词 |
| `本地测试结果.json` | 本机 128 项模拟测试的结果记录 |

## 二、安装（首次）与更新（已有旧版）

### 关键原则：**原地覆盖，不要卸载**

卸载会让扩展 ID 变化，`chrome.storage` 里保存的 **API Key、设置、待复习题目** 全部丢失。

### A. 已经装过旧版（0.1.5x / 0.1.6x / 0.1.7x）

1. 打开课程页，点扩展图标 →「暂停」。
2. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）。
3. 找到「课程流程助手」→「详细信息」→ 记下 **“加载已解压的扩展程序”那一行的路径**。
4. 先把那个文件夹整个复制一份备份（例如改名 `backup-1017`）。
5. 把本版解压出的 **全部文件** 复制进去 →「替换目标中的文件」。
   - 必须整批覆盖。只拷 `content.js` 会造成新旧混搭：探针有新字段、功能却不生效。
6. 回扩展页点卡片上的 **重新加载**（转圈箭头），确认版本显示 **0.1.74**。
7. 把所有学习通标签页逐个 **F5** 刷新。

### B. 这台浏览器还没装过

1. 打开 `edge://extensions` 或 `chrome://extensions`，开启右下角「开发人员模式」。
2. 点「加载解压缩的扩展」→ 选择**含 `manifest.json` 的那个文件夹**（注意：是文件夹，不是压缩包）。
3. 打开课程页刷新 → 点扩展图标 → 在「答题接口密钥」里填 API Key（DeepSeek 的 `sk-...`）→ 点「保存资料」。

### C. 装完怎么确认成功

| 检查点 | 应该看到 |
|---|---|
| 扩展卡片版本 | `0.1.74` |
| 面板里是否有「答题方式」下拉 | 有，且有三项 |
| 点「复制页面探针」 | 开头 `"version": "0.1.74"` |

## 三、快速开始（三步）

1. **填密钥**：扩展面板 →「答题接口密钥」粘贴 `sk-...` → 保存。
2. **打开课程**：进入课程目录页（`mooc2-ans/mycourse/stu` 或旧版目录页均可）。
3. **点「开始」**，然后把浏览器窗口放在**可见、不被遮挡**的位置。

之后它会自己跑：找未完成的小节 → 进章节 → 答题 → 提交 → 播视频 → 回目录 → 下一节。

## 四、功能介绍

### 4.1 三种答题方式（面板「设置 → 答题方式」）

| 方式 | 调用接口 | 是否填写/提交 | 题目是否入库 |
|---|---|---|---|
| **AI 作答**（默认） | 是 | 是 | 只存"猜的题"和"平台判错的题" |
| **随机作答（不调用接口）** | **否，零 token** | 是，全部随机选（填空填「无」） | **全部** |
| **只收集题目（不填写、不提交）** | 否 | **不填不交**，读完即暂停 | **全部** |

- 想"先把题看一遍再决定怎么做" → 选「只收集题目」，导出 Markdown 慢慢看。
- 想"零消耗跑完整门课" → 选「随机作答」。

### 4.2 自动流程覆盖到哪一步

- 识别新版目录（`mooc2-ans`）与旧版目录（`studentcourse`）两种入口
- 进入章节后自动判断：这节有视频 / 有测验 / 有文档
- 视频：自动首播、卡住自动续播、自动处理视频中的弹题（答错会自动换一个选项重答一次）
- 测验：读题 → 取答案 → 填写 → **核对选中状态** → 勾选自动提交时才提交 → 处理提交确认弹窗
- 完成后自动回目录找下一节，直到没有未完成项

### 4.3 取答案的策略（0.1.74 起改为分批）

一次把 9 道题塞进一个请求，模型很容易直接返回空答案。现在改成：

1. **分批请求**：题目超过 3 道就拆成**每批 3 道**分别请求；3 道以内、以及视频弹题这类单题，仍然是 1 次请求，不会多花钱。
2. **逐题补问**：某批漏答/空答时，只对这一批缺的那几道单独追问，**缺几题补几题**（旧版最多只补 6 道，长卷子必卡）。
3. **部分作答不硬停**：如果全部补问后仍有题没拿到答案，脚本会带着「已答出的部分」继续走，然后看第 4 条。
4. **随机兜底**：勾选「取不到答案时随机选一个」→ 剩下的选择题随机补上、全部存进待复习、继续填写并提交；**没勾** → 明确写出「接口只为 X/Y 道题给出答案，已暂停」，并提示可以勾哪个开关。

> 网络类/HTTP 类错误（超时、401、402、429、5xx）不参与上面的重试，第一时间停下报错，避免白白烧重复的请求。

### 4.4 截图策略（省 token）

- 题目里有 `<img>` 或 CSS 背景图 → **直接读图片文件**，不截图，不受窗口影响。
- 只有"文字读不出来"或题干出现「下图/如图/表中/见图/图1」等字样时 → 才截图。
- 单份测验 **最多截 4 张**。
- 截图失败 → 自动改用文字作答，不中断。

### 4.5 容错链（从轻到重）

```
暂态错误 → 2/5/10/15 秒退避重试 4 次（0.1.54）
      ↓ 仍失败
长卷子（>3 题）→ 拆成每批 3 道分别请求（0.1.74）
      ↓ 某批空答案 / 漏答
      逐题补问这一批缺的题，缺几题补几题（0.1.74）
      ↓ 仍有题没答出来
勾了随机兜底 → 随机选一个继续，并全部存进待复习（0.1.71）
      ↓ 仍跑不动
自动刷新页面并续跑，最多 3 次（0.1.73）
      ↓ 仍失败
停下，写明具体原因，等你处理
```

> 「没答全」这类原因**不会**触发自动刷新（避免同一个请求重复烧三遍），只会停下来等你决定。

### 4.6 待复习 / 题库导出

- 面板「导出待复习」按钮 → 下载 `course-runner-review-日期.md`
- 内容：题干、全部选项、你的选择、原因（平台判错 / 接口无答案随机选 / 随机作答 / 仅收集题目）
- 按题号去重，重复跑不会越堆越多（上限 200 条）

### 4.7 诊断三件套

| 按钮 | 得到什么 | 什么时候用 |
|---|---|---|
| 导出日志 | `course-runner-log-日期.json`，脱敏事件流 | 出错时给 AI |
| 复制页面探针 | 当前页面结构线索（版本、帧、选择器命中、信号计数） | 卡在"识别不到"时 |
| 清除日志 | 清空本机日志 | 想重新开始记录 |

> 探针与日志都**不含**题目、答案、截图、课程链接、账号或密钥。

### 4.8 设置项一览

| 设置 | 默认 | 说明 |
|---|---|---|
| 答题接口密钥 | 空 | DeepSeek `sk-...`，必需 |
| 模型 | 你上次的选择 | 文字通道用；带截图时走图片模型 |
| 课程资料 | 空 | 可选，贴教材片段提高准确率 |
| 自定义答题提示词 | 空 | 可选，最多 500 字 |
| 答题方式 | AI 作答 | 见 4.1 |
| 自动提交章节测验 | 开 | 关掉则填完就暂停，你手动交 |
| 验证码自动识别（测试） | 关 | 仅尝试一次，失败会停 |
| 取不到答案时随机选一个 | 关 | 打开才能"永远不停" |
| 连续失败自动刷新页面（最多 3 次） | 开 | 卡死自救 |

## 五、报错了怎么办

先看**面板状态栏那一行字**——现在每一类停靠都写了具体原因。对照下表处理。

### 5.1 页面/窗口类

| 面板提示 | 原因 | 怎么办 |
|---|---|---|
| 无法读取题目截图（Failed to capture tab / 窗口被遮挡） | 浏览器窗口不在可见状态（被别的窗口盖住、最小化、熄屏） | 把课程窗口拉到最前；或用「只收集题目/随机作答」绕开截图 |
| 课程标签页不是当前活动标签 | 同一窗口切到了别的标签 | 0.1.60 起会自动切回；若仍失败，手动点一下学习页标签 |
| 检测到的新版目录属于另一门课程 | 课程号/班级号确实不同 | 确认后重新点开始；0.1.53 起同课程不会再误判 |
| 页面正在切换章节，等待平台确认后继续 | 正常过渡 | 不用管 |
| 答完这节没自动进下一节 | 目录未加载完 | 0.1.74 会自动刷新重试；3 次仍失败时手动刷新点开始 |

### 5.2 接口类（看状态码）

| 面板提示 | 含义 | 怎么办 |
|---|---|---|
| 答题接口请求失败，状态码 401 | 密钥无效 | 重新粘贴 API Key |
| 状态码 402 / Insufficient Balance | 余额不足 | 充值（0.1.69 起会显示服务商原话） |
| 状态码 429 | 限流 | 等 1–5 分钟后重新点开始 |
| 状态码 4xx 且带 Model Not Exist | 模型名不存在 | 面板「模型」换成 `deepseek-chat` |
| 状态码 5xx | 服务端故障 | 等一会儿再试 |
| 答题接口等待超时，请稍后重试 | 请求发出但 60 秒无响应 | 先看是否被 VPN/加速器拦（UU、aTrust 等），临时退出再试；0.1.74 会自动刷新重试 |
| 答题接口未给出可用答案（模型说：…） | 模型拒绝作答 | 看括号里它说的话；多半是题目文字不全，检查是否需要截图 |
| 答题接口漏答了部分题目 | 模型只答了一部分 | 0.1.74 起会分批请求并逐题补齐；真出现这条说明补问也失败了，按下面那条处理 |
| 接口只为 X/Y 道题给出答案，已暂停 | 接口确实答了，但没答全 | **推荐**：勾选「取不到答案时随机选一个」→ 随机补全、存进待复习，不用重跑；不想随机就手动补做这几道 |
| 答案为空，正在重新请求（第 k/2 次） | 自动重试中 | 不要干预，等它跑完 |

### 5.3 答题/提交类

| 面板提示 | 原因 | 怎么办 |
|---|---|---|
| 题目 N 的页面选中状态与答案不一致 | 点击没生效或状态读不出 | 0.1.57 起会重试 3 轮；仍失败请复制页面探针 |
| 题目 N 的 X 项选中状态读不出来 | 页面用了无法识别的样式 | 把探针发我，我按这个页面补规则 |
| 提交确认框已弹出，但没识别出确认按钮 | 弹窗结构不认识 | 手工点一次「提交」，然后把探针发我 |
| 确认按钮已点击，但弹窗仍未关闭 | 平台慢/网络问题 | 手工点一次「提交」再刷新核对 |
| 上一节测验提交状态尚未确认 | 提交结果没落地 | 刷新目录看是否已显示分数/已提交；再点开始只核对，不会重答 |
| 验证码错误一次，已暂停 | 识别失败 | 手动输验证码，然后重新点开始 |

### 5.4 其他

| 面板提示 | 怎么办 |
|---|---|
| 扩展与课程页连接已断开 | 刷新课程标签页，再点开始 |
| 已自动刷新 3 次仍未恢复 | 真的卡住了：看括号里的上次原因，或关掉自动刷新后手动排查 |
| 卡片变灰 / 清单文件缺失 | 覆盖时漏了 `manifest.json`，重新整批覆盖 |
| 扩展页出现两个「课程流程助手」 | 移除旧的，只留一个（两个会抢着点页面） |
| 版本没生效（探针里还是旧版本号） | 第 6 步的「重新加载」没点，或没刷新课程页 |

## 六、出错时给 AI 的提示词（直接复制）

### 6.1 完整版（推荐）

```
【课程流程助手 0.1.74 出错，请帮我定位】
1) 面板现在显示：〈把面板状态栏那行字原样粘贴，例如“答题接口请求失败，状态码 402（Insufficient Balance）”〉
2) 扩展版本：0.1.74（探针里 version 也是 0.1.74）
3) 我在做什么：〈例如：点开始后自动进入某节，读完 9 道题就停了〉
4) 已经试过：〈例如：刷新过页面 / 重新点过开始 / 换过模型〉
5) 日志（导出日志的 JSON 全文，或直接给文件）：〈粘贴/附件〉
6) 页面探针（复制页面探针的全文）：〈粘贴〉

请判断属于哪一类：脚本问题 / 页面结构变化 / 接口或网络问题；
然后给出：① 现在这一步我该点什么、② 需要改哪项设置、③ 如果代码要改，具体改哪一处。
不要让我反复手动点开始，也不要建议卸载重装（会丢设置）。
```

## 七、省 token 的几条建议

1. **答题方式**保持「AI 作答」；纯练手/不需要成绩时用「随机作答」，完全零消耗。
2. **截图按需**：不要为了"更准"强行打开全部截图，图片 token 是文字的数倍。
3. **模型**用 `deepseek-chat` 足够；`reasoner` 类模型会显著增加输出 token。
4. 一份测验的请求数是 **1 次整批 + 最多 6 次补问**；如果经常补问，说明题目文字质量差，考虑填「课程资料」提高命中率。
5. 「导出日志」不影响 token，只读本地数据。

## 八、边界与风险（务必读一遍）

- 本工具只在你自己的账号、你自己的课程上使用；**提交动作是真实发生的**，会占用该节成绩与任务点。
- 随机作答、随机兜底都会产生**可能是错的答案**，用之前请确认你接受这个结果。
- 「验证码自动识别」仅尝试一次，失败即停，不做绕过。
- 密钥只存在浏览器本地 `chrome.storage`；不会上传到任何第三方（只发给你配置的 DeepSeek 接口）。
- 探针与日志已脱敏：不含题目、答案、截图、课程链接、账号、密钥。
